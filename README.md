# 📚 D Books

D Books is a book management web application built using HTML, CSS, and JavaScript.

The application allows users to add and delete books dynamically through a clean popup interface while practicing core JavaScript DOM manipulation concepts.

## ✨ Application Workflow

1. Click the "+" button.
2. Enter Book Title.
3. Enter Author Name.
4. Enter Book Description.
5. Click ADD.
6. The book card is dynamically created and displayed.
7. Click Delete to remove a book.
